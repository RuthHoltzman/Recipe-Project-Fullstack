# 👨‍🍳 Recipe Management System - Full Stack Project



## 🇮🇱 עברית - אודות הפרויקט
מערכת לניהול ושיתוף מתכונים הכוללת ממשק משתמש מתקדם ומערכת ניהול (Admin) עוצמתית. הפרויקט נבנה בדגש על הפרדה מלאה בין צד הלקוח לצד השרת ושימוש בשיטות עבודה מודרניות.

### 🌟 תכונות עיקריות
* **מערכת הרשאות:** ניהול תפקידים (צופה, מעלה תוכן, מנהל).
* **לוח בקרה (Dashboard):** ניהול מתכונים ומשתמשים בזמן אמת.
* **אישור משתמשים:** תהליך אישור מובנה למשתמשים המבקשים להעלות תוכן.
* **רשימת תפוצה:** ייצוא מהיר של מיילים של משתמשים רשומים.
* **תאימות סביבתית:** ניהול כתובות API דרך Angular Environments.

---

## 🇺🇸 English - About The Project
A comprehensive recipe management and sharing system featuring an advanced user interface and a robust Admin dashboard. Built with a full-stack architecture, focusing on scalability and clean code practices.

### 🌟 Key Features
* **Role-Based Access:** Management of Roles (Viewer, Uploader, Admin).
* **Admin Dashboard:** Real-time recipe and user moderation.
* **Approval Workflow:** Built-in system for approving new content uploaders.
* **Mailing List:** Fast export of subscribed users' email addresses.
* **Environment Configuration:** Dynamic API URL management.

---

## 🛠 טכנולוגיות / Tech Stack

* **Frontend:** Angular 17+ (Standalone Components, RxJS, Bootstrap 5).
* **Backend:** Python 3.x (Flask Framework).
* **Database:** SQLAlchemy / SQLite.
* **Security:** Flask-Login & Route Guards.
